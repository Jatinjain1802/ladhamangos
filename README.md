# ladhamangos

Responsive React + TypeScript design preview for **Ladda's Alphonso Mangoes**. A product showcase with WhatsApp enquiries, not an online shop.

## Run locally

Requires Node.js 22 or newer.

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

## Included

- Mobile and desktop layouts in mango yellow, cream and green
- Brand header, hero, mango showcase, story and enquiry sections
- WhatsApp links to the requested temporary number, +91 8959526978
- Keyboard focus styles, reduced-motion support and descriptive image text
- No checkout, payments, backend, analytics or form data collection
